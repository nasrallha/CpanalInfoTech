# لوحة التحكم (infotech-cpanel)

لوحة إدارة العملاء (الشركات) والباقات والاشتراكات وموظفي الدعم.
مشروع منفصل عن البرنامج الأساسي، وليه قاعدة بيانات لوحده (`infotech_cpanel`).

## التشغيل أول مرة (على جهازك)

1. اعمل قاعدة البيانات واليوزر في MySQL (Workbench):

   ```sql
   CREATE DATABASE infotech_cpanel CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   CREATE USER 'cpanel_user'@'localhost' IDENTIFIED BY 'باسورد_قوي';
   GRANT ALL PRIVILEGES ON infotech_cpanel.* TO 'cpanel_user'@'localhost';
   FLUSH PRIVILEGES;
   ```

2. انسخ `.env.example` باسم `.env` وعدّل:
   - `DATABASE_URL` ببيانات القاعدة.
   - `PANEL_SECRET_KEY`: 32 حرف أو أكتر عشوائي (احتفظ بيه، هنحطه في البرنامج الأساسي كمان).
   - `ERP_URL`: رابط البرنامج الأساسي.

3. نزّل المكتبات واعمل الجداول:

   ```
   npm install
   npm run db:migrate -- --name init
   ```

4. شغّل اللوحة:

   ```
   npm run dev
   ```

   وافتح `http://localhost:3100`. أول مرة هتطلب منك تعمل حساب **صاحب اللوحة**.

## الحالة

- ✅ الدخول وصاحب اللوحة، الموظفين والأدوار والصلاحيات
- ✅ الباقات، الأنشطة، الإعدادات
- ✅ الشركات: تسجيل (كود عشوائي + اسم قاعدة مقترح)، تعديل، تجديد، تغيير باقة، إيقاف/تفعيل/إلغاء، السجل
- ✅ سجل العمليات
- ⏳ إنشاء قاعدة الشركة فعلياً (الجداول + مدير الشركة) — المرحلة الجاية
- ⏳ ربط البرنامج الأساسي، الدخول كدعم فني، متابعة الاستخدام
